# CSS Grid y Flexbox

Material **didáctico** para aprender las propiedades de **CSS Grid** y **Flexbox** con ejemplos interactivos.

## Contenido
- `grid.html`: `grid-template-columns`, `grid-template-rows`, `gap`, etc.
- `flex.html`: propiedades de contenedor y de elemento de Flexbox.
- `scripts/`: ejemplos interactivos para ver los cambios en vivo.

## Cómo ejecutar
Abre `grid.html` o `flex.html` en el navegador.

## Proyecto de aprendizaje
Ejercicios de maquetación CSS moderna.
